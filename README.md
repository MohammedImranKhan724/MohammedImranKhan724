### 🚀 Featured projects

**[Forager](https://github.com/MohammedImranKhan724/Forager)** — Full-stack food-donation platform
A layered .NET 8 solution (Domain → Application → Infrastructure → API/Web) with dual synchronized state machines
driving the donation lifecycle across donor, delivery-agent, and admin roles. OTP + JWT auth with device-scoped
refresh tokens, a claims-based permission system, and Redis-backed distributed caching via FusionCache (fail-safe
reads, tag-based invalidation) — cutting API response times ~30%. Dockerized end-to-end.
`ASP.NET Core 8` `EF Core` `SQL Server` `Redis` `FusionCache` `JWT` `Razor Pages` `Docker`

**[Mike.Ecommerce](https://github.com/MohammedImranKhan724/Mike.Ecommerce)** — E-commerce microservices platform
A 9-service .NET 8 platform (Identity, Catalog, Basket, Discount, Ordering, Payment, Inventory, Notification, Search)
behind a YARP gateway. CQRS with MediatR vertical slices, polyglot persistence (PostgreSQL, SQL Server, SQLite,
Elasticsearch), a MassTransit/RabbitMQ order-fulfillment saga with compensating transactions and a transactional
outbox/inbox pattern, plus full observability via Serilog/Seq, OpenTelemetry/Jaeger, and Prometheus/Grafana.
`.NET 8` `MediatR` `MassTransit` `RabbitMQ` `YARP` `gRPC` `Docker Compose` `Prometheus/Grafana`
